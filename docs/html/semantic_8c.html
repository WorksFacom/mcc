Detailed Description

implementação do analisador semântico.

este módulo percorre a árvore sintática abstrata (ast) para realizar checagens de tipo, de declaração e de escopo. ele utiliza a tabela de símbolos como uma estrutura de dados auxiliar para manter o contexto do código, como as variáveis, arrays e funções declaradas em cada escopo.
